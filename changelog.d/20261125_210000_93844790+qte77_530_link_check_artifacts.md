### Security

- `persist-offer` now link-checks the match, CV, cover letter and gap report with the same line scan as the prefill pack (#530).
  - A CV and a cover letter keep only the candidate's own links from the local evidence library. A link from the posting does not belong in them.
  - The match and the gap report also keep the job record's url and the posting's links and emails.
  - A failing line is replaced by a fixed note, and a `link-check.md` sidecar names the file and the count without repeating the removed text. Per-file counts in `result.json` keep the sidecar on re-render.
  - The record is read from `jobs-raw.json` once for both checks.
- The script-scheme rule no longer flags a bold label that ends in a scheme word, such as `**Languages and data:** Python`. A scheme glued to anything else (`data:**x`) still counts.
- `persist-offer` never rewrites or removes its input file. That file is unchecked agent output and the only copy of a replaced line, so read it as text and never open it as a rendered document.
