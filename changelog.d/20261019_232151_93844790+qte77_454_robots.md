### Added

- Every network fetch (ingest adapters, `probe`, `refresh`, `verify-sources`, `prefill-fields`, `discover-slugs`) goes through `polite_fetch`, which obeys robots.txt for `User-agent: *` and spaces requests to the same host by max(1 s, `Crawl-delay`). A 4xx robots.txt means no rules; a 5xx or network error skips the host, shown as a failed source in the ingest summary (#454).
