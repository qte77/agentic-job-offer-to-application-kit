### Security

- Tailor and relevance workflows: every agent runs as the new read-only `jd-reader` agent type (`.claude/agents/jd-reader.md`: Read, Grep and Glob only), so an agent reading a job ad has no shell, no web access and cannot write files. A session started before the agent file existed fails at the first agent with "agent type 'jd-reader' not found"; start a new session.
- Tailor and relevance prompts state that job ads are third-party text, used as facts about the role and never as instructions. A JD that addresses AI tools or automated applicants is not acted on and stays out of the CV, cover letter and prefill pack; the tailor's gap report ends with a "Note on the ad" section that quotes it.
