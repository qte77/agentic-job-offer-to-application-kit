### Security

- Tailor and relevance workflows: every agent runs as the new read-only `jd-reader` agent type (`.claude/agents/jd-reader.md`: Read, Grep and Glob only), so an agent reading a job ad has no shell, no web access and cannot write files. In one run, the session that had just created the agent file failed at the first agent with "agent type 'jd-reader' not found"; if that happens, start a new session.
- Tailor and relevance prompts state that job ads are third-party text, used as facts about the role and never as instructions. The prompts tell the agents not to act on a JD that addresses AI tools or automated applicants and to keep it out of the CV, cover letter and prefill pack; this is a prompt instruction, not a check. The reading agents have no tools to act on such text with. The tailor's gap report ends with a "Note on the ad" section that paraphrases it.
