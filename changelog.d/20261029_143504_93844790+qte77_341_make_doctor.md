### Added

- `make doctor` checks the setup the network-touching subcommands need and prints what is missing: the `polyfetch-scrape` checkout, its patchright Chromium (launched via `polyfetch doctor`, and the binary path asserted on disk, because a sandboxed `patchright install` can exit 0 without writing anything) and `results/evidence-library.json`. `make doctor FIX=1` installs a missing Chromium; run it unsandboxed.
