### Fixed

- `polite_fetch` now matches robots.txt rules per RFC 9309 on every supported Python: `*`
  wildcards, a trailing `$` end anchor, and the longest matching rule wins (`Allow` on a tie).
  Before Python 3.14, `urllib.robotparser` ignored wildcards and applied the first matching rule,
  so on Python 3.11-3.13 a path such as jobs.ch's slugged `/en/vacancies/detail/*/*/*` pages was
  treated as allowed. The new `RobotsRules` gives the same answers as the Python 3.14 parser on
  jobs.ch's live robots.txt.
