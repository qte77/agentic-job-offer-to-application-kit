### Fixed

- `ajoa-kit refresh` now marks deleted postings stale. polyfetch raises some terminal 4xx
  (404/410 `GoneError`, 401/403 `AuthRequired`) as typed errors instead of returning a response,
  and the liveness probe (`slug_probe.fetch_status`) swallowed every error as "inconclusive", so a
  404/410 posting was always kept as live. The probe now returns the error's 4xx status; network
  errors and 5xx stay inconclusive. An audit on 2026-11-10 found 8 score-5 ads answering 404/410
  that `refresh` had not flagged. `verify-sources` is unaffected (any 4xx was already "not live").
