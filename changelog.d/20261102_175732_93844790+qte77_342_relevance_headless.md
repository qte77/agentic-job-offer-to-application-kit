### Added

- `make relevance_headless` runs the relevance screen as detached headless `claude -p` slices
  (`scripts/relevance_headless.sh`; `SLICES`, `RANGES="start:limit ..."`, `MAX_AGENTS`,
  `MIN_FREE_MB`). Each slice starts with a pre-recorded `--session-id`, logs stay under
  `results/run/relevance/`, the free disk is checked before each slice, and
  `CLAUDE_CODE_PRINT_BG_WAIT_CEILING_MS=0` lifts the 10-minute `-p` wait that otherwise stops a
  long workflow (#342).
- `ajoa-kit collect-relevance <sessions.txt> --out FILE` and `make relevance_collect` combine the
  slices from their Claude Code workflow journals (one row per JD, higher score kept on re-runs),
  then `persist --merge`. Missing batches stop the run with a ready `RANGES="..."` re-run line.
  Verified against a 201-batch run: 201/201 batches, the same 2,101 JDs and scores (#342).
